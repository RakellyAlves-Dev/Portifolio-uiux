Respostas rápidas sobre meu processo de trabalho e disponibilidade.

Qual é o seu prazo médio para entrega de um projeto de UI/UX? +

O tempo varia conforme o escopo do projeto. Redesigns de pequenas landing pages levam cerca de 1 a 2 semanas, enquanto sistemas web complexos e aplicativos mobile completos podem levar de 4 a 8 semanas.

Você também faz o desenvolvimento do site (Front-end)? +

Sim! Além de desenhar toda a experiência (UI/UX no Figma), desenvolvo interfaces web modernas e responsivas utilizando HTML, CSS e JavaScript funcional.

Como funciona o seu processo de trabalho? +

Meu fluxo se divide em 4 etapas: 1. Descoberta e alinhamento de objetivos; 2. Pesquisa de UX e prototipagem de baixa fidelidade; 3. Design de Interface (UI) e testes; 4. Entrega de style guide, arquivos no Figma e/ou código funcional.

Você está disponível para contratação em tempo integral? +

Sim, estou aberta a propostas de trabalho remoto ou híbrido, seja em modelo CLT ou PJ, além de projetos freelances pontuais.
